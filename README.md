# Reels Bot

Telegram-бот: надсилаєш посилання на рілз з Instagram або Facebook — у відповідь отримуєш відеофайл.

## Деплой на Render

1. У Telegram відкрий **@BotFather** → `/newbot` → скопіюй токен.
2. Залий цю папку в новий репозиторій на GitHub (файли `.env` і `cookies.txt` туди не потрапляють — вони в `.gitignore`).
3. На [dashboard.render.com](https://dashboard.render.com): **New → Blueprint** → вибери репозиторій.
   Render прочитає `render.yaml` і створить безкоштовний Web Service.
4. Коли попросить `BOT_TOKEN` — встав токен від BotFather. `WEBHOOK_SECRET` згенерується сам.
5. Дочекайся деплою (перший раз ~3–5 хв) і напиши боту `/start`.

Адреса webhook підставляється автоматично (`RENDER_EXTERNAL_URL`), налаштовувати нічого не треба.

**Про безкоштовний план:** після 15 хв без повідомлень Render присипляє сервіс. Перше повідомлення після паузи
будить його — відповідь прийде із затримкою ~30–60 с, далі швидко.

## Cookies (якщо Instagram/Facebook не віддає відео)

Instagram майже завжди блокує завантаження з серверів без входу в акаунт. Тоді:
1. Встанови в браузер розширення **Get cookies.txt LOCALLY**.
2. Зайди в instagram.com (і facebook.com) під акаунтом, експортуй cookies у файл `cookies.txt`.
3. На Render: сервіс → **Environment → Secret Files → Add** → ім'я `cookies.txt`, встав вміст файлу → Save.
   Render перезапустить бота.

Краще використовувати окремий (не основний) акаунт — Instagram може його обмежити.

## Оновлення yt-dlp

Instagram і Facebook часто змінюють сайт. Якщо бот перестав завантажувати — на Render натисни
**Manual Deploy → Clear build cache & deploy**: підтягнеться свіжий yt-dlp.

## Локальний запуск (для перевірки)

Створи `.env` з `BOT_TOKEN=...` (за зразком `.env.example`) і запусти:
```bash
.venv/bin/python bot.py
```
Локально бот працює через polling. Якщо паралельно працює версія на Render, локальний запуск зніме webhook —
після перевірки перезапусти сервіс на Render.

## Обмеження

- Telegram дозволяє ботам надсилати файли до 50 МБ — бот автоматично знижує якість, якщо треба.
- Приватні дописи завантажуються лише з cookies акаунта, який має до них доступ.
